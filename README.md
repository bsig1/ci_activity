## Reflection
CI is used often in production environments as a defense against
erroneous changes to software. By running a set of tests before allowing
merging into the main branch, many errors can be prevented. This allows
continuously integrating features and code into an existing product (as
is expected within agile) without destroying existing work and without creating
product downtime for the client.
